# 休講情報通知システム

## システム名
PSS 2

## システム機能
大学ポータルサイトに記載されている休講情報をブタウザ拡張機能スクレイピングし、GoogleスプレッドシートとGoogleAppScriptによって構成された簡易サーバーに休講日を保存する。保存された情報をもとに休講のある日の朝にLINEで自動通知する。

## リポジトリ目的
システムで運用されているすべてのコードの記録

## ディレクトリ構造
BlowserExtentionとGoogleAppScriptによって構成されている。前者には拡張機能のコードが、後者にはgasのコードが記録されている。

## AIの運用について
原則としてバイブコーディングは禁止。ただし処理フローの案出しや記述の仕方、構文の解説など補助的なAI使用は認める。
